# 魔兽世界 3.4.3 (54261/52237) 补丁制作指南

针对巫妖王怀旧服 3.4.3 客户端（build 54261 / 52237）的资源补丁制作说明：替换 DB2、模型、材质，或制作 Hotfix 热修。

## 目录说明

| 路径 | 说明 |
|---|---|
| `3.4.3.54261/DBFilesClient/` | 预先从 54261 客户端导出的 DB2 文件，与 52237 通用 |
| `fileid和文件路径对照表.txt` | 客户端内所有文件的 ID 与路径对照，添加新模型/法术时需要 |

## 工具

- **CASCExplorer**：从魔兽客户端中导出 DB2、材质、模型、内置插件等一切资源。
- **黑兔软件 → 工具中心 → DB2 编辑器**：打开/修改 DB2 文件（如同 3.3.5 的 DBC），也可导出 CSV 用于制作 Hotfix 热修文件。

## 打补丁前的准备

在客户端 `WowClassic.exe` 同级目录下新建文件夹 `patch-343`

## 三种补丁方式

### 1. 直接替换文件

将 CASCExplorer 导出的 DB2、模型等文件，**按客户端原有目录结构**复制进 `patch-343`，用黑兔启动客户端即完成资源替换。

示例：`patch-343\DBFilesClient\Spell.db2`

### 2. Hotfix 热修（推荐）

> ⚠️ 大多数情况下**不建议直接改 DB2 文件**：黑兔可能会自行修改 DB2 或制作热修文件来修 BUG，直接改动会造成覆盖冲突。

1. 在 `patch-343` 下新建文件夹 `Hotfix`；
2. 用黑兔的 DB2 编辑器导出 CSV；
3. **删除 CSV 中全部数据，只保留第一行表头**；
4. 添加自己的热修数据。

示例：`patch-343\DBFilesClient\Hotfix\Spell.csv`

> ⚠️ Hotfix 是**增量更新**：只保留你新增或修改的行，切勿把导出的全量 DB2 数据都放进去。

### 3. 添加 FileID（导入新文件）

DB2 中引用资源只使用 `fileid` 而非文件路径。需要导入新模型等文件时：

1. 在 `patch-343` 下新建文件夹 `fileid`；
2. 将你的文件**重命名为目标 fileid** 后放入该文件夹。

示例：`patch-343/fileid/12351252` —— 客户端查找 fileid 为 `12351252` 的文件时，将使用你的新文件。
